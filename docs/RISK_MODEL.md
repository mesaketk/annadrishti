# Risk model spec — `pipeline/04_risk.py` + `pipeline/06_export.py`

Inputs (all keyed by `lgd`): artifacts/crops_latest.parquet, crops_district_year.parquet, yield_sensitivity.parquet,
climate_district.parquet, social_district.parquet, gee_live.json (optional), buffer_stocks.json, enso_status.json.

## 1. Scenario → expected rainfall anomaly per district
| scenario | JJAS anomaly used (district‑specific) |
|---|---|
| `neutral` | `neutral_mean_anomaly_pct` (≈0) |
| `elnino` | p_elnino·`elnino_mean_anomaly_pct` + (1−p_elnino)·`neutral_mean_anomaly_pct`, with p_elnino = IRI MJJ‑2027 El Niño probability (0.61) for the kharif‑2027 horizon; for rabi 2026‑27 use tmax Feb‑Mar El Niño anomaly |
| `elnino_strong` | `strong_elnino_anomaly_pct` (2002/2009/2015 analog mean) |

## 2. Expected yield shock (%)
`expected_yield_shock_pct = clip(beta_d × anomaly_scn / anomaly_elnino_hist, −45, +10)` where
`beta_d = foodgrain_elnino_pct` (empirical El Niño‑year deviation from trend) if n_elnino_years ≥ 3, else state median, else national median.
Scale by rainfed exposure: `shock × (0.4 + 0.6 × rainfed_share)` (irrigated districts buffered). Report by group too (cereals/millets/pulses/oilseeds).

## 3. Components (each rank‑normalised to 0‑1 across districts, higher = worse)
- **Exposure E** = 0.5·z(|expected_yield_shock_pct|) + 0.3·z(elnino_deficit_prob) + 0.2·z(−jjas_anomaly latest year) *(dry antecedent year worsens)*; if `climate.live` present add 0.15·z(−ndvi_anom) and renormalise.
- **Sensitivity S** = 0.30·rainfed_share + 0.20·top_crop_share + 0.15·yield_cv10 + 0.20·small_marginal_share + 0.15·(1 − self_sufficiency clipped 0‑1.5 /1.5).
- **Adaptive‑capacity deficit C** = 0.30·stunting + 0.15·wasting + 0.15·child_anaemia + 0.10·women_bmi_low + 0.15·pds_dependency + 0.15·clim_vuln_index (NFHS‑6 preferred, else NFHS‑5; each rank‑normalised; missing component → reweight the rest).
- **score** = 100 × (0.45·E + 0.30·S + 0.25·C). Bands fixed from the `elnino` scenario tertiles: ≥ 67 high, 34‑66 medium, else low (same thresholds for all scenarios so counts move with the scenario).
- **drivers**: list of {name, contrib} = weight × normalised value for each component term, sorted desc, top 8, plus a `label` in plain English (e.g. "86 % of cropped area is rainfed").

## 4. Food balance
requirement_t = population_2026 × 0.18 t (ICMR‑NIN ≈ 180 kg cereals+pulses/person/yr); edible_prod_t = foodgrain_prod_t × 0.875;
self_sufficiency = edible/requirement; pds_dependency = pds_rice_wheat_t_latest12m / requirement.
Scenario‑adjusted: `edible_prod_scn = edible × (1 + shock/100)`; `deficit_t_scn = max(0, requirement − edible_prod_scn)`.

## 5. Hindcast (credibility)
For years Y ∈ {2009, 2014, 2015, 2023}: recompute score using only data available before Y (anomaly = actual JJAS anomaly of Y as the "forecast", sensitivity from trailing years), and report `actual_foodgrain_yield_dev_pct` (deviation from trend in Y). Output per district `hindcast[Y] = {predicted_score, actual_dev}`. In the report: Spearman correlation between predicted score and actual deviation across districts per year (should be negative). State it honestly in the UI.

## 6. KPIs (`artifacts/kpis.json`)
as_of, enso (from enso_status.json), central_pool (from buffer_stocks.json latest), per scenario: counts by band, people_in_high_risk (sum population_2026), children_u5_in_high_risk, national expected production shock % (production‑weighted), total deficit_t, districts_below_self_sufficiency; hindcast correlations.

## 7. Export (`06_export.py`)
Assemble SCHEMA.md objects → `artifacts/districts.json` (array, 753), `artifacts/timeseries/{lgd}.json` (merge the three timeseries folders), `artifacts/kpis.json`. Copy the three to `web/public/mock/` too (so the static build has real data as fallback). Print a validation report: null coverage per field, score distribution, top‑20 high‑risk districts under `elnino`, and a sanity cross‑check that Marathwada/Vidarbha/Bundelkhand/Rayalaseema/KBK Odisha/south Rajasthan rank high (they should — if not, investigate before "fixing" weights).

## 8. v2 — extra sources (`artifacts/extra_district.parquet`)
Three terms added inside the existing components. Each is **rank-normalised over scored districts**, has an **effective weight of 0.10** inside its component (the other terms of that component, including live NDVI, are scaled by 0.90), and a missing value drops the term and reweights the rest of the component (never imputed as 0). Top-level weights 0.45/0.30/0.25, beta, scenarios and bands-from-elnino-tertiles are unchanged.
- **price_spike_risk (Exposure)** = rank(0.5·clip(`price_elnino_spike_pct`, 0, +40)/40 + 0.5·`price_volatility_idx`); needs both inputs. Only positive El Niño-year farm-gate price spikes count: in the ICRISAT data the median spike is negative (prices fell vs trend in El Niño years), so the term is mostly a price-volatility proxy. Same value in all scenarios. Label: "El Niño-year farm-gate price spike +12% (ICRISAT, main crop Paddy)" (volatility label when spike ≤ 0).
- **groundwater_stress (Sensitivity)** = `gw_stress_idx` (0-1 rank of pre-monsoon depth and 10-yr deepening), rank-normalised. Label: "Pre-monsoon water table 12.4 m, deepening 0.3 m/yr (CGWB 2019)".
- **poshan_underweight_live (Capacity deficit)** = rank(`poshan_underweight_pct`), Poshan Tracker latest month. Level is not NFHS-comparable (administrative, integer-rounded, ~18 pp lower); only rank is used, and it carries a state reporting-practice bias (e.g. Andhra Pradesh). Label: "Poshan Tracker Feb-2026: 18% of measured children underweight".
- Hindcast recomputes with the new terms (they are contemporary snapshots, so it is even less out-of-sample). `data_quality` gains `has_price`, `has_groundwater`, `has_poshan`; `capacity_terms` now counts up to 7 and `sensitivity_terms` up to 6.
- Export (SCHEMA Addendum D): `markets`, `groundwater`, `nutrition.poshan_live`, `crops.economics` per district; `kpis.data_coverage` gains `with_price_*`, `with_groundwater*`, `with_poshan_live`, `with_crop_economics`, `scored_with_*_term`. `web/public/mock/timeseries` ships only the 10 showcase districts (486, 358, 191, 673, 502, 441, 426, 525, 290, 118); the full set stays in `artifacts/timeseries`.

## 9. v3 — ML ensemble for the expected yield shock (`04b_ml_ensemble.py` → `04_risk.py` → `06_export.py`)
**What changed.** `risk.<scenario>.expected_yield_shock_pct` is now `shock_ensemble_pct` from `artifacts/ml_ensemble.parquet` (weighted mean of the analog formula of §2 and a LightGBM model; weights analog 0.48 / LightGBM 0.52, proportional to 1/pooled out-of-sample MAE), with the analog formula as fallback (`expected_shock_source` = "ensemble" | "analog"; the analog value stays in `expected_yield_shock_analog_pct`). Everything downstream is unchanged and just consumes the new shock: exposure terms (re-referenced to the new elnino shock distribution), food balance / deficits / grain pre-positioning, tertile bands, priority ranks. `shock_by_group` follows the foodgrain shock with the analog group/foodgrain β ratios (ratio 1 when |β| < 2 pp, clipped ±3). Driver label: "Expected foodgrain yield loss 4.7% (ensemble of analog −2.8% and LightGBM −6.5%, spread 5.1 pp)".

**Why.** Target = foodgrain yield deviation from the trailing-10-year Theil-Sen trend (same as the hindcast actual). Leave-one-year-out over 22 monsoon years (13,267 district-years): LightGBM rank correlation ρ = 0.31 vs analog 0.08 (shipped-β analog 0.14, leaky), MAE 16.1 vs 17.7 pp (predict-0: 17.0 pp); the ensemble sits between (ρ 0.28, MAE 16.3) and is shipped because it keeps the interpretable ENSO-analog signal and its disagreement (`spread_pct`) is a confidence flag. The analog's in-sample hindcast ρ (−0.09…−0.53) was optimistic: β is fitted on all years including the test year.

**Hindcast.** `hindcast[Y]` gains `predicted_shock_lgbm_oos_pct` (and `predicted_shock_analog_oos_pct`), the leave-year-out prediction for that district-year (`artifacts/_ml_loyo_preds.parquet`). `kpis.hindcast[Y]` gains `rho_lgbm_oos`, `rho_analog_oos`, `rho_ensemble_oos`, `gap_*_oos`. Sign conventions differ and must be labelled in the UI: in-sample `spearman_rho` = Spearman(risk score, actual dev), negative = good; `rho_*_oos` = Spearman(predicted shock, actual dev), positive = good; `gap_*_oos` negative = good. Out-of-sample is leave-one-year-out, not a forecasting backtest (training includes future years).

**TimesFM (display-only).** `models.timesfm` carries the BigQuery AI.FORECAST JJAS-2027 rainfall anomaly (ONI-covariate TimesFM 3.0 primary, univariate 2.5 alongside), its p10/p90, and the 6-month Poshan underweight forecast. It does not enter the score or the ensemble: hindcast district-level correlation is −0.06…+0.26 and RMSE is no better than climatology, the median forecast is biased ~5-10 pp low, and ONI beyond JAS-2026 is an assumption. Use it for national direction only (`kpis.models.timesfm`).

**TabFM.** Evaluated as a third member (zero-shot tabular foundation model) but infeasible here: 6.6 GB weights not fully cached and CPU inference of a 3,000-row context exceeded 8 min per fold (22 folds > budget). The `tabfm` slot stays null in `ml_ensemble.parquet`; the code path is kept and the weights renormalise automatically if it is ever enabled.

**Export.** `districts.json[].models` (SCHEMA Addendum E: `expected_shock_source`, `by_scenario`, `weights`, `skill`, `timesfm`), `kpis.models` (skill table, weights, TimesFM national means for both variants, Poshan 6-month national trend), `kpis.data_coverage.with_ensemble / with_timesfm* / with_hindcast_oos`. Run order: `04b` → `04_risk` → `06_export`; 04b reads the analog shock from `expected_yield_shock_analog_pct` of the previous export so re-running it does not feed the ensemble back in as "analog".

## 10. v4 — seasons: every year, every season (`08_enso_status.py` → `04b` kharif → `04b --season rabi` → `04_risk` → `06_export`)
Implements SCHEMA Addendum F. Supersedes §1's p(El Niño)-weighted `elnino` scenario (see "Phases are pure"). Everything not listed here (S and C components, weights 0.45/0.30/0.25, v2 terms, hindcast formula for kharif, ensemble weights) is unchanged.

**Keys.** Scenario ids are `<season>:<phase>` with phase ∈ `lanina | neutral | elnino | elnino_strong | current`; season ids come from `enso_status.outlook_seasons` (today `rabi_2026_27`, `kharif_2027`). `risk` carries all 10 keys plus the legacy aliases `neutral | elnino | elnino_strong` = `kharif_2027:*` (same content). Files: `actions_<season>_<phase>.csv` (10) and the three legacy names as copies of the kharif ones.

**ENSO status (`08_enso_status.py`, monthly).** Refreshes the NOAA CPC ONI table (only if the download parses, is not shorter and agrees with the current 2000–2025 values within ±0.30 °C; otherwise refused and logged), the CPC discussion (status, Niño indices, next update) and the IRI El Niño probabilities (text of the Quick Look / Technical Update; the plume probabilities are published as figures only). `p_by_season`: rabi = mean of NDJ / DJF / JFM, kharif = MJJ of the following year; where the text gives no neutral / La Niña split the non-El-Niño remainder is split with the ratio of the previous release (default 0.85 : 0.15). Offline or on parse failure nothing changes (a missing `p_by_season` is derived once from the stored plume).

**Phases are pure; `current` is the mix.** v3 weighted the analog by p(El Niño) = 0.61 inside `elnino` while LightGBM was already pure El Niño (an inconsistent hybrid). v4: `elnino` = El Niño weight 1 for every member, `neutral` = 0 by construction (analog), `elnino_strong` = 2002/2009/2015 analog mean, `lanina` = below. `current` = Σ p_k · shock_k over lanina / neutral / elnino (p from `p_by_season`; OND-main districts use the rabi-season p for their kharif mix, as v3 did), then scored through the normal pipeline (food balance, exposure, bands). Effect at the switch: kharif `elnino` analog mean shock −4.48 % (was −2.75 %), ensemble −5.52 % (was −4.70 %); `neutral` / `elnino_strong` unchanged; elnino scores v3→v4 Spearman 0.989.

**Kharif La Niña = flood scenario.** shock = β_LaNiña (mean foodgrain deviation in La Niña years − neutral years, ≥ 3 obs each, clipped to [−40, 15], state/national-median imputed) only where the district's La Niña-year mean main-season rain anomaly is > +15 % **and** β_LaNiña < 0; otherwise 0 (benign). The La Niña ML row (La Niña-year mean climate, ONI −1.0) is gated the same way (ensemble = 0 outside flagged districts, ≤ 0 inside). Exposure: loss term as usual; hazard term `rain_excess_risk` = share of La Niña years with > +15 % rain, flagged districts only, percentile vs the El Niño deficit-probability distribution; antecedent term as kharif. 59 districts flagged, 3 end in the high band.

**Rabi (`<rabi>:*`).**
- *Data*: season-split foodgrain yields from `01_crops` (`rabi_fg_yield_t_ha`, `kharif_fg_yield_t_ha`, `*_prod_t`, `*_area_ha`, `rabi_pulses_prod_t`; kharif = Kharif + Autumn + Winter labels, rabi = Rabi, Summer / Whole Year in neither). Season labels are unreliable in Bihar, Odisha, West Bengal, Assam, Jharkhand.
- *Target / features / harness (04b --season rabi)*: rabi yield deviation from the trailing-10-year Theil–Sen trend (crop year Y = sown Oct Y, harvested Mar Y+1); features OND anomaly (Y), JJAS anomaly (Y), Feb–Mar tmax anomaly (Y+1), ONI NDJ (Y), previous kharif and rabi deviation, irrigated share, groundwater stress, small/marginal share, top-crop share, rabi share, state, lat, lon; leave-one-year-out 2003–2024 (Y+1 dropped from training). Analog = phase β (El Niño / La Niña years minus neutral years, refit without the held-out year), no irrigation buffer (terminal heat hits irrigated wheat). Pooled LOYO: LightGBM rho 0.317 / MAE 17.4 pp, analog rho −0.01 / MAE 19.7 pp, predict-0 MAE 18.6 pp; ensemble weights 1/MAE (analog 0.47, LightGBM 0.53). The analog has no out-of-sample skill; it is kept as the interpretable ENSO member and its disagreement with LightGBM is the `spread` flag.
- *Scenario rows*: phase-year means of the climate features (El Niño 2002/04/06/09/15/18/23, La Niña 2000/07/10/11/20/21/22, strong 2002/09/15, neutral rest), ONI NDJ of the phase years, last observed (2024) previous deviations. **LightGBM scenario shocks are relative to the district's own neutral-winter prediction** (raw predictions are deviations from a lagged trend with a +3 to +6 pp level, dominated by the carried-over deviation).
- *Exposure*: 0.5 × expected rabi yield loss (percentile vs the rabi El Niño distribution; zero loss → 0) + 0.3 × terminal-heat hazard (share of the phase's winters with Feb–Mar tmax anomaly ≥ +0.5 °C, percentile vs rabi El Niño) + 0.2 × weak previous kharif (rank of −(2024 kharif deviation)), plus live NDVI and the price term as in kharif. OND anomaly is a model feature, not an exposure term (OND % anomalies are unstable where normals are small); groundwater stress stays in S. S and C shared with kharif.
- *Eligibility*: rabi foodgrain area ≥ 2,000 ha in ≥ 3 of 2018–2024, median ≥ 2,000 ha and ≥ 5 % of foodgrain area → 547 of 719 scored districts; the rest are `no_data` for rabi (`negligible_rabi_foodgrain` 158, `rabi_season_label_gap` 14: Odisha, Kerala, Dadra-NH).
- *Food balance / actions*: the shock is applied to the rabi share of foodgrain production only (median 2021–23): `edible_s = edible + rabi_prod × 0.875 × shock`; `grain_preposition_t` = deficit_s − deficit_neutral (PDS wheat lifting). Menu (Addendum F): timely sowing before 15 Nov (`lead`), heat-tolerant / early varieties (`seed_bank_ha` = 0.2 × rabi foodgrain area, band ≠ low), 1–2 protective irrigations (`protective_irrigation_ha` = rabi area × irrigated share, band ≠ low), groundwater budgeting (`groundwater_budget_flag`: gw_stress_idx ≥ 0.67 and band ≠ low), PDS wheat lifting (`grain_preposition_t`); `pulses_preposition_t` uses rabi pulses production × the rabi foodgrain shock; anganwadi / anaemia / PMFBY / MGNREGA (high band) / fodder formulas as kharif. `actions.season` and `lead` per season.

**Bands.** One threshold pair for every season and scenario: tertiles of `<kharif>:elnino` (low < 44.9, high ≥ 55.4). Exposure percentiles reference each season's own El Niño distribution, so scores compare *relative* vulnerability across seasons, not tonnes lost (rabi El Niño mean shock −1.4 % vs kharif −5.5 %). Band counts (high / medium / low): kharif lanina 3/95/621, neutral 25/182/512, elnino 240/239/240, strong 297/216/206, current 126/253/340; rabi lanina 61/176/310, neutral 20/194/333, elnino = current 135/196/216, strong 283/169/95 (206 rabi `no_data`).

**Rabi hindcast** (crop years 2009, 2015, 2021 (March-2022 heatwave), 2022; `hindcast_rabi` per district, `kpis.hindcast_rabi`): leave-one-year-out ensemble shock (level de-biased by the pooled LOYO mean) + observed Feb–Mar heat indicator + same-year kharif deviation → score; Spearman(score, actual) −0.11, −0.27, −0.17, −0.09 (right sign, weaker than kharif; in 2009 and 2015 ~97 % of districts were heat winters so the heat term cannot discriminate). OOS LightGBM rho 0.14–0.39.

**Honest reading of the wheat belt.** Feb–Mar heat explains rabi yield deviations in Karnataka, Andhra Pradesh, Assam, Maharashtra, Bihar, West Bengal (−4 to −18 pp per +1 °C) but is flat in Punjab, Haryana, Uttar Pradesh, Rajasthan; El Niño winters were not systematically hotter or lower-yielding there; and those states have low S and C. So Punjab / Haryana / UP stay low-risk in rabi (mean rabi score 29 / 30 / 45) and the rabi high-risk set is led by Jharkhand, Karnataka, Telangana, Andhra Pradesh, tribal Madhya Pradesh / Maharashtra. Reported as found, not tuned.

**Export (06).** `districts[].risk` (all keys + aliases; drivers trimmed to the largest count that keeps the file < 15 MB: top 3, and top 2 for neutral / elnino_strong — 14.9 MB), `hindcast_rabi`, `season_context.rabi`, `models.by_scenario` for all keys (`current` = probability-weighted mix; legacy keys keep the `tabfm: null` slot, new keys omit it), `kpis.outlook`, `kpis.by_season_scenario[season][phase]` (counts, people, children, national shock, deficit, `actions_total`), `kpis.hindcast_rabi`, `kpis.models.rabi`, `kpis.band_counts_by_scenario`; the legacy `scenario_counts`, `by_scenario`, `actions_total`, `top_states` keep their three old keys (kharif).
